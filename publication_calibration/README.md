# Paired-test calibration reports

Run `python paper1_calibration_report.py` from the repository root. This needs
only the Python standard library and writes a new report directory. Use
`--verify-only` to verify compact sources without writing, or `--output NEW_DIR`
to name a new or empty directory. No simulations or model fits are run.

The count grid has 24 scenarios with 1,000 replicates each. The targeted
diagnostics have six selected scenarios with 500 fresh replicates each, six
analysis arms, and two standard-error estimators. All coefficient differences
are null. Original inputs, estimates and p values are unchanged.

The report keeps planned-family and retained-family BH results separate.
Coverage, marginal rejection, extreme tails and Bonferroni errors answer
different questions. The report makes no automatic estimator selection.

`manifest.json` verifies every compact source and records the hash of its
original export. The two design JSON files retain scientific scenario settings
without local filesystem metadata. The simulation engines remain in
`paired_count_calibration/` and `paired_tail_diagnostics/` with their original
protocol identities. Adding this reporting module does not change a completed
simulation protocol.

`gaussian_geometry.R` reproduces the fixed-design variance-quadratic diagnostic
from `tail_design.json`. Its moment-equivalent degrees of freedom are descriptive,
not an implemented replacement test. Run from the repository root:

```bash
Rscript publication_calibration/gaussian_geometry.R NEW_OUTPUT.csv
```

Figures 10, S14 and S15 use these inputs through the existing Python figure
entry point. Tables S22-S23 supply compact scenario-level evidence. Full
replicate and event records are generated by the simulation workflows, not
expanded into the supplementary workbook.
