设计模块版本为 0.2.0；核心复现协议仍为 2.1.0。投稿数值表来自已经完成的
48,000 个高斯数据集和 4,800 个计数数据集。直接核验和重画投稿图不需要重新模拟：

```bash
python verify_publication.py
python paper1_plot_figures.py
```

对已有完整结果重新生成汇总，使用根目录的 `paper1_design_fix.py --previous-results`。
完整命令及新的 36 进程实验入口见 [投稿复现说明](../docs/PUBLICATION.md)。

## 运行方式

把以下三个项目一起放入服务器代码目录：

- `design_extension/` 整个目录
- `paper1_design_oneclick.py`
- `run_design_extension.sh`

```bash
conda activate paper1
bash run_design_extension.sh
```

默认36进程，每个进程内部1线程。不拉取GitHub，不安装软件，不重新下载研究数据。
默认运行小规模检查：144个计数数据集，每个600基因、5个模型；另有4,800个小型高斯数据集。
数据准备串行，模拟阶段并行。运行时间根据服务器已完成批次估计。

程序从代码目录同级的已完成复跑中查找三个输入：
`core/prepared/mouse_units.csv`、`mouse_whole_counts.csv.gz`、`mouse_cortex_counts.csv.gz`。
它选择元数据修改时间最新的合格目录，并打印输入位置及记录校验值。需要锁定某次复跑时使用：

```bash
bash run_design_extension.sh --data-work /完整复跑目录/core
```

这些已整理计数和元数据只读；生成器参数重新估计，新增实验全部重新拟合。
不读取旧系数、旧p值、旧模拟结果或投稿绘图数据。原论文复现入口及结果不变。
缺R依赖时停止；使用 `--r-library /已有/R_library` 指定已有库，可重复填写。

## 新增内容

1. EWI、协变量条件下的组内信息比、目标可估计性、有效信息笼数及信息集中程度。
2. OLS和给定协方差下的解析偏差敏感性；通过配对高斯生成验证。
3. 72只动物，12/18/36个笼，4种混合比例；完整留出18笼设计。
4. 五模型计数流程：重新过滤、TMM、权重估计、拟合、经验贝叶斯、BH。
5. 仅用训练设计制定的条件化筛选规则，再用留出设计评价。
6. 相同设计下改变笼均值的配对比较、自动报告、断点续跑及精简核验包。

EWI是已有的组内/总平方和比值；无额外协变量时等于1减笼指标回归的R²。
它能描述信息来源，不能单独决定FDR。简单线性模型中遗漏笼均值项的偏差为
`gamma*(1-EWI)`，这需要明确的零条件均值误差等假设。
真实元数据报告不声称能估计实际FDR。

EWI为0时不推荐固定效应或Mundlak，因为目标组内效应不可估计。
高斯随机效应臂采用已知协方差，只用于机制检查，不冒充dream。
计数臂使用原五模型统计代码。

## 正式网格

小规模检查结果正常并核验后，再运行：

```bash
bash run_design_extension.sh --profile full
```

正式配置为12种布局×8种条件×50次，合计4,800个完整计数数据集，使用完整共同基因背景；
另有48,000个高斯数据集。50次是起始精度设置，需检查蒙特卡洛不确定性。
若采用200次，可加 `--count-reps 200`，计数数据集增至19,200个，必须使用新输出目录。
不要把小规模结果写成正式验证。

条件化规则按给定的笼均值幅度、潜在笼SD和非零效应比例分别筛选。
这些生成参数在真实数据中未知，因此不是通用自动选型器。
规则要求训练设计有足够重复、平均可用性至少99%，且平均FDP的单侧95%蒙特卡洛上界不超过0.075。
0.075是预先声明的经验筛选容差，BH名义水平仍为0.05，不代表证明控制FDR。
不满足条件会输出不推荐任何模型。

## 查看进度及续跑

启动时打印短输出目录 `p1_design_月日_时分秒`。把下面的目录换成实际打印值：

```bash
python paper1_design_oneclick.py --status --output /实际输出目录
bash run_design_extension.sh --resume --output /实际输出目录
```

原入口续跑须重复原科学参数和输入选项；`paper1_design_fix.py --resume` 从实验配置恢复参数。
允许修改进程数，不允许混合不同代码、数据或依赖版本的结果。
0.2.0 的计数任务逐数据集写入检查点，校验通过的已完成数据集可以复用。
0.1.0 实验继续计算时须使用原始源码；新版本可只读汇总其完整结果。
不要修改协议版本来绕过校验，也不要删除锁文件。前台运行用 Ctrl+C 停止。

全局零假设下使用精确 Clopper-Pearson 区间。含非零效应时，平均 FDP 使用
Student-t 蒙特卡洛区间；全部 FDP 为零时使用保守零事件上界。
历史结果中未记录的逐基因诊断不会由汇总数反推生成。

结束后自动生成同级 `_review.zip`，只带设计、汇总、数据集级指标、规则和报告。
把这个ZIP带回来即可；不必传计数矩阵、逐基因表及整个运行目录。
完整运行目录保留错误日志和失败记录。

## 实现范围

- 通用的“EWI低于某值就必然FDR失控”阈值；这不由设计矩阵单独确定。
- FDR的Shapley归因、Hausman触发的模型选择。
- 新机器学习模型、独立外部生物学队列。
- 不等笼大小、残差离散度的系统扩展网格。
- 可安装的R包；当前提供独立Python/R命令行工具。

这几项不属于当前软件的已实现功能。已有正式结果、输入校验值及表图对应关系
保存在 `publication_figures/` 与 `publication_tables/` 中。

完整方法和测试命令见 [英文说明](README.md)。
