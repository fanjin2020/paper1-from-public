# Compact supplementary tables

`data/` contains the 98 numerical sections in Supplementary Tables S1-S23.
`manifest.json` specifies the row and column counts, SHA256 checksums and scope
of each section. Blank values mean unavailable, not zero.

S2.1 contains all records significant in either matched human association arm.
S4.1 contains the union of full-family model-based or HC3 coefficient-change
discoveries and the 40 base-significant clinical records. Their q values retain
the original 17,064-position testing family. Other included sections retain all
rows of their stated summary. Full gene-level outputs are generated by the
analysis pipeline; all publication figure inputs are supplied separately.

Export plain CSV files without extra dependencies:

```bash
python publication_tables/export_tables.py --output publication_tables/output
```

This command validates the checksums and writes only to a new or empty directory.
It does not fit models or recalculate statistical results.

S22 contains the full 24-scenario paired count calibration summaries. S23
contains all six-scenario control summaries, marginal extreme tails, stated
paired contrasts, expression-stratum event rates and Gaussian variance geometry.
These add 261 compact rows; replicate-level records remain in the full analysis
outputs. The reported HC3 q values in S4 are model-dependent sensitivity results,
not a calibration-certified discovery list. See the S22-S23 controls.
